# LIFF

[LIFF (LINE Front-end Framework)](https://developers.line.biz/en/docs/liff/overview/) is a platform for building web apps that work with LINE.

This repository provides links to LIFF resources and hosts security advisories for the LIFF SDK (`@line/liff`).
The LIFF SDK source code is not hosted in this repository.

## Why this repository?

This repository helps developers find LIFF SDK security advisories, including information about affected versions and fixes.
Developers can also watch this repository for advisory updates.

## Security

### Security advisories

See this repository's [Security Advisories](https://github.com/line/liff/security/advisories) for published advisories about the LIFF SDK.

### Reporting a vulnerability

Report suspected LIFF SDK vulnerabilities privately to [ml-bug-report@lycorp.co.jp](mailto:ml-bug-report@lycorp.co.jp), following the [reporting guidelines](https://bugbounty.linecorp.com/en/).

## Questions and bug reports

For information about technical support, see the [LINE Developers FAQ](https://developers.line.biz/en/faq/#i-need-technical-support).

To report a non-security issue with the LINE Platform or request an improvement, use the [LINE Platform inquiry form](https://contact-cc.line.me/serviceId/11556).

For issues specific to a related project, refer to that project's documentation.
